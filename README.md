## Aturan Singkat

1. Jangan kerja langsung di branch `main`; buat branch per fitur (lihat `docs/panduan-git.md`).
2. Jangan pernah meng-upload file rahasia (`.env`, key database, key payment gateway).
3. Update file di folder `docs/` kalau ada keputusan baru.
