# Alur Sistem E-Commerce Zaxcellphone

Alur ini hasil diskusi kelompok. Ada 3 jalur utama.

## 1. Jalur Pembeli
Beranda → Katalog → Detail Produk & Harga → Keranjang → Checkout → Isi Data Pembeli → Pembayaran (payment gateway) → Konfirmasi

## 2. Jalur Admin
Login → Dashboard → Menu Produk → Tambah / Edit / Hapus → Atur Harga & Stok → Simpan

## 3. Jalur Pemesanan
Pesanan Masuk → Admin Cek Stok → Verifikasi Pembayaran → Proses → Kirim Barang → Perbarui Status

## Catatan
- Pembayaran memakai payment gateway (bukan transfer manual).
- Tempel gambar diagram alur di folder ini (misalnya `diagram-alur.png`).
